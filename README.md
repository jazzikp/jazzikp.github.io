# 彭哲健 · Zhejian Peng

Personal site: **[jazzikp.github.io](https://jazzikp.github.io)**

I write about recommendation systems, ads ranking, and applied machine learning. This is also a place for notes from courses, experiments, and things I want to remember.

## Local preview

```bash
bundle install
bundle exec jekyll serve
```

Then open [http://localhost:4000](http://localhost:4000).

GitHub Pages serves this repository at [jazzikp.github.io](https://jazzikp.github.io).
